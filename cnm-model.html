Mathematical & Physical Formulation

The Channel Network Model (CNM) represents heterogeneous fractured rock as a discrete network of interconnected 1D channel segments. Node hydraulic heads (Hi) are solved numerically via a Gauss-Seidel Finite Difference scheme:

Σ Cij (Hi - Hj) = 0

Channel conductances (Cij) follow a log-normal distribution generated using Box-Muller transformations. Fluid flow through each channel segment is calculated using Darcy's relation: Qij = Cij (Hi - Hj), and solute transport is simulated by advecting tracer particles with velocity proportional to channel flow fluxes.
